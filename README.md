# Projeto de Engenharia de Software

Desenvolvimento de um software em Java, com utilização de dependências, desenvolvimento de testes
e outras features.

## Planejamento Scrum — Jira

O gerenciamento e a organização das atividades do projeto foram realizados com o método Scrum no Jira
As funcionalidades foram organizadas em histórias de usuário (User Stories), distribuídas entre Sprints e Backlog, de acordo com as prioridades e etapas de desenvolvimento.

### História de usuário — US-04: Calcular pontuação e apresentar resultado final

**Título da tarefa:** Calcular pontuação e apresentar resultado final

**Descrição:**
Como jogador, quero receber pontos de acordo com a proximidade entre meu palpite e a nota correta do filme para acompanhar meu desempenho durante a partida.

**Critérios de aceite:**
- Calcular a pontuação conforme a diferença entre o palpite e a nota correta do filme.
- Garantir que palpites com menor diferença recebam maior pontuação.
- Acumular automaticamente a pontuação de cada rodada.
- Apresentar a pontuação final após a conclusão das cinco rodadas.

**Organização no Jira:**
- História de usuário: US-04.
- Identificação da tarefa: MG-5
- Status: Backlog.
